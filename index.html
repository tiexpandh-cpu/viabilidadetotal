Bem-vindo ao ExpandhVia PRO

Ferramenta completa de viabilidade financeira para loteamentos. Calcule TIR, VPL, margem líquida, fluxo de caixa e exposição de capital com precisão profissional.

Como começar

Preencha as Premissas (área, preço, custos), configure as Fases de Venda e o Cronograma de Obras, depois clique em ⟳ Recalcular ou use Ctrl+Enter.

💡 Use os cenários Pessimista / Realista / Otimista no cabeçalho para testar diferentes projeções rapidamente.

Premissas do Projeto

Configure os parâmetros fundamentais que alimentam todos os cálculos.

Área e Produto

Área Total é a área bruta do terreno em m². A Eficiência define quanto dessa área vira lote vendável (típico: 45–60%). O Tamanho do Lote determina a quantidade total de lotes.

Preços e Custos

Preço/m² é o preço de venda do lote. Custo Infra/m² cobre terraplanagem, drenagem, pavimentação, água, esgoto e energia — calculado sobre a área total. Custo Terreno é o valor de aquisição.

Regime Fiscal

Lucro Presumido Simples: 4% sobre receita. Lucro Presumido: 6,73%. Lucro Real: 34% sobre lucro apurado (simplificado).

⚠ O Lucro Real nesta ferramenta é uma estimativa simplificada. Consulte sempre um contador.

Fases de Venda

Distribua o VSO (Velocidade de Saída de Obra) ao longo do tempo em fases. A soma deve ser 100%.

Cada fase tem: % do total de lotes, mês de início e duração em meses. O VSO/mês é calculado automaticamente.

ℹ A velocidade de vendas impacta diretamente o fluxo de caixa e a TIR. Fases mais curtas no início melhoram o breakeven.

Cronograma de Obras

Configure quando cada etapa da obra será executada e como o custo se distribui.

Distribuições disponíveis: Curva S (concentrado no meio), Linear (igual por mês) e Final (concentrado no último mês, para medições).

Estrutura de Recebimento

Defina como os compradores pagarão — os 3 baldes representam modalidades de pagamento.

Balde 1 — À Vista: pagamento único com desconto. Balde 2 — Curto Prazo: entrada + parcelas de até 36 meses. Balde 3 — Longo Prazo: entrada + parcelas de até 120 meses com correção monetária.

💡 Aumentar o balde à vista reduz a exposição máxima de capital e antecipa o breakeven.

Análise de Sensibilidade

Teste como variações no VSO e no preço de venda impactam os indicadores.

Use os sliders para ver o efeito em tempo real, ou gere a Matriz 2D para visualizar todas as combinações possíveis de uma vez.

Indicadores Financeiros

IndicadorDescrição
TIRTaxa Interna de Retorno anualizada. Compara com o custo de oportunidade (TMA).
VPLValor Presente Líquido. Positivo = projeto cria valor acima da TMA.
Margem LíquidaLucro líquido / VGV bruto. Referência: acima de 15% é saudável.
Exposição MáximaMaior saldo negativo acumulado — capital necessário para o projeto.
BreakevenMês em que o fluxo acumulado cruza zero.
ROIRetorno sobre o investimento total (custos).

Cenários

Os botões Pessimista / Realista / Otimista aplicam multiplicadores sobre as premissas base.

O cenário Otimista aumenta 10% no preço, reduz 5% no custo de infra e acelera 30% as fases de venda. O Pessimista faz o inverso.

⚠ Editar campos enquanto um cenário está ativo reseta para Realista antes de capturar os novos valores.

Gerenciamento de Projetos

Salve múltiplos projetos localmente com IndexedDB no navegador, ou sincronize com Supabase para acesso em qualquer dispositivo.

Use Exportar JSON para fazer backup ou compartilhar um projeto. Importar JSON restaura qualquer arquivo exportado anteriormente.

ℹ O Comparador de Cenários permite carregar até 3 projetos salvos lado a lado para análise comparativa.

Diagnóstico IA

O módulo ✦ Diagnóstico IA envia todos os indicadores calculados para o Claude (API Anthropic) e retorna um parecer estruturado em linguagem natural.

O diagnóstico inclui: veredicto geral, pontos fortes, alertas de atenção, riscos críticos e sugestões concretas de otimização.

💡 Use o botão "Incluir no PDF" para anexar o diagnóstico ao relatório gerado.
⚠ Requer conexão com a internet e uma chave de API Anthropic configurada no servidor.
